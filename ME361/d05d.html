Where we are

Part C decided when to sample; this part decides what number each sample becomes

In part C a conditioned analog voltage was sampled every \(\delta t\) seconds. Three rules came out of it: sample faster than twice the highest frequency present (\(f_s > 2f_m\)), put an analog low-pass (anti-alias) filter in front of the sampler, and make the record hold whole periods so the spectrum does not leak.

But a sample is still an analog value, for example 6.372 V. A computer can only store whole numbers of a fixed length. Two devices make the crossing between the two worlds:

Analog-to-digital converter (A/D converter, ADC): turns one held voltage into an integer code. This rounding of a continuous value onto a finite set of levels is called quantization.

Digital-to-analog converter (D/A converter, DAC): turns an integer code back into a voltage, for example to drive a valve or a motor.

Recap of part A

A word is a row of switches, and each switch is worth twice its right-hand neighbour

Bit (binary digit): the smallest unit of information, either 0 or 1, like a switch that is off or on. A word is an ordered row of \(M\) bits; a byte is a word of 8 bits. The memory location that holds a word is a register.

Reading from the right, the bits are worth 1, 2, 4, 8, … A bit that is 1 adds its weight; a bit that is 0 adds nothing. In straight binary the value of the word is

Value of an M-bit straight-binary word $$X=\sum_{k=0}^{M-1} b_k\,2^{k},\qquad 0\le X\le 2^M-1$$
\(b_k\)value (0 or 1) of bit \(k\); bit 0 is on the right \(M\)number of bits in the word \(2^M\)number of different words: 256 for 8 bits, 4096 for 12, 65 536 for 16

Bit \(M-1\) carries the largest weight and is the most significant bit (MSB); bit 0 is the least significant bit (LSB). Long words are often written in hexadecimal: each group of 4 bits becomes one digit 0–9 or A–F (A = 10 … F = 15).

A 4-bit register holds 0101 in straight binary. What decimal number is it?

  1. Weights from the left: 8, 4, 2, 1. Value \(=0\cdot 8+1\cdot 4+0\cdot 2+1\cdot 1=5\).

Binary codes

Negative numbers: let the top bit carry the sign

Straight binary is a unipolar code: every value has the same sign, which suits a 0 to 10 V input. A bipolar code also represents negative values (a ±5 V input, a signed temperature difference). In all the bipolar codes below the MSB acts as the sign bit.

Offset binary cuts a bipolar range into 16 equal bins; true zero lies between 0111 and 1000, labelled −0 and +0. Ones' complement negates by inverting every bit. Sign + magnitude puts the sign in the MSB and the size in straight binary (1100 = −4). BCD (binary-coded decimal), used in digital readouts, codes each decimal digit separately: 532 → 0101 0011 0010.

Two's complement is the code computers use for signed integers. Reveal why it works:

  1. An \(M\)-bit register can only hold \(2^M\) values, so arithmetic wraps round: for \(M=4\), \(15+1\) gives 0000 with the carry lost.
  2. So store \(-x\) as \(2^M-x\). For \(M=4\): \(-3\to16-3=13=1101\).
  3. Quick recipe: invert every bit and add 1. \(0011\to1100\to1101\). Same answer.
  4. Check by adding: \(5+(-3)\): \(0101+1101=1\,0010\). Drop the carry out of bit 3 and you get 0010 = 2. Ordinary binary addition just works, which is why hardware likes this code.
  5. Range: \(-2^{M-1}\) to \(2^{M-1}-1\). With 8 bits, −128 to +127. There is one more negative value than positive because zero uses a code with MSB = 0.

A car's 4-digit odometer driven backwards one kilometre from 0000 shows 9999. Read 9999 as −1 and you have ten's complement. Two's complement is the same trick on an odometer whose wheels only carry 0 and 1.

HIGH and LOW: how a word travels on wires

8-bit registerHIGH (1)LOW (0)

Electronics represents a bit by a voltage. In 5 V TTL (transistor–transistor logic) a HIGH of about 5 V means 1 and a LOW of about 0 V means 0. A receiver accepts anything from 2 to 5.5 V as HIGH and anything below about 0.8 V as LOW. The undefined gap in between is a noise margin: a half-volt spike on a LOW line still reads LOW.

Parallel transmission uses one wire per bit, so the whole word arrives at once. Serial transmission uses one wire and sends the bits one after another, each held for a fixed time \(\delta t\), so a word takes \(M\,\delta t\).

Parallel is an eight-lane bridge: a whole word crosses side by side. Serial is a single-lane bridge: the bits queue up, but you only have to build one lane.

Press Load 10110011: unsigned 179, two's complement −77. Press Negate: 01001101 = +77. Now set 01111111 (+127) and press Add 1. The pattern becomes 10000000, which two's complement reads as −128: integer overflow wraps round, it does not stop at the top.

Digital-to-analog conversion

The D/A converter: each bit switches in half the current of the bit before it

\(E_{ref}\)stable reference voltage, V \(c_m\)state of bit \(m\) (1 = switch closed); \(m=1\) is the MSB \(R,\ R_r\)MSB resistor and feedback resistor, Ω \(X\)the word read as a straight-binary integer

The problem: turn an \(M\)-bit word into a proportional voltage. Reveal the circuit's logic line by line.

  1. An ideal op-amp with negative feedback holds its two inputs at the same voltage. The + input is grounded, so the − input sits at 0 V: a virtual ground.
  2. A closed switch therefore puts the full \(E_{ref}\) across its resistor. Bit \(m\) carries \(c_m E_{ref}/(2^{m-1}R)\): the MSB the most, each lower bit half as much.
  3. No current enters the op-amp, so all branch currents add and flow on through \(R_r\): $$I=E_{ref}\sum_{m=1}^{M}\frac{c_m}{2^{m-1}R},\qquad E_o=-I R_r$$
  4. The word as an integer is \(X=\sum c_m 2^{M-m}\), so \(\sum c_m 2^{1-m}=2X/2^M\) and \(|E_o|=E_{ref}\,(2R_r/R)\,X/2^M\).
  5. Choose \(R_r=R/2\): the output is the reference scaled by the fraction \(X/2^M\).
D/A converter output $$|E_o|=E_{ref}\,\frac{X}{2^M}$$

Assumes an ideal op-amp, exact resistor ratios and zero-resistance switches. The minus sign only reflects the inverting amplifier. Typical full-scale ranges are 0–10 V or ±5 V, with \(M\) = 8, 12, 16 or 18 bits.

Worked example

Output of a 4-bit weighted-resistor converter

The converter on the previous slide has \(E_{ref}=10\) V, \(R=10\) kΩ (so the branches are 10, 20, 40 and 80 kΩ) and \(R_r=5\) kΩ. It holds the word 1010. Find the summing current, the output voltage, the size of one output step and the largest output.

Known \(M=4\), word 1010, \(E_{ref}=10\) V, \(R=10\) kΩ, \(R_r=5\) kΩ. Find \(I\), \(|E_o|\), one LSB, maximum output. Assumptions ideal op-amp and switches.

  1. Closed switches: the MSB (10 kΩ) and the third bit (40 kΩ). Their currents are \(10/10\,000=1.00\) mA and \(10/40\,000=0.25\) mA.
  2. Summing current: \(I=1.00+0.25=1.25\) mA.
  3. Output: \(|E_o|=IR_r=1.25\ \text{mA}\times5\ \text{k}\Omega=6.25\) V (the inverting stage gives −6.25 V).
  4. Check with the output law: \(X=1010_2=8+2=10\), so \(E_{ref}X/2^M=10\times10/16=6.25\) V.
  5. One LSB changes the output by \(10/16=0.625\) V. The largest word, 1111, gives \(15\times0.625=9.375\) V, one step short of \(E_{ref}\).

What this means: a 4-bit converter can only output 16 voltages, 0.625 V apart. Anything in between is unreachable, which is why real D/A converters use 12 or more bits.

Weighted resistors need a spread of \(2^{M-1}\): a 16-bit version would need resistors from \(R\) to \(32\,768R\), all matched to better than 1 part in 65 536. Practical converters use the R-2R ladder. Looking to the right from any node you see exactly \(2R\), so the current splits in half at every node and each bit again contributes half of the bit before. The output law \(E_{ref}X/2^M\) is unchanged.

Analog-to-digital conversion

The A/D converter: a staircase with steps of size Q

An A/D converter has an analog side and a digital side. The analog side accepts inputs within its full-scale range \(E_{FSR}\): the span from the lowest to the highest input, for example 0 to 10 V (unipolar) or −5 to +5 V (bipolar), both \(E_{FSR}=10\) V. The digital side delivers an \(M\)-bit word, so it can only report \(2^M\) different values. The span is therefore cut into \(2^M\) equal steps:

A/D converter resolution $$Q=\frac{E_{FSR}}{2^M}$$
\(Q\)resolution: the input change that moves the output by one LSB, V \(E_{FSR}\)full-scale range (span), V \(M\)number of bits

For \(E_{FSR}=10\) V: 8 bits give \(Q=10/256=39.1\) mV; 12 bits give \(10/4096=2.44\) mV.

Two encoding schemes are common. A truncating converter changes code at \(Q, 2Q, 3Q,\dots\), so the output is always 0 to 1 LSB below the input (usual in digital readouts). A converter with a ½-LSB bias shifts the input internally by \(Q/2\), so the steps fall at \(Q/2, 3Q/2,\dots\) and the output is within ±½ LSB of the input (usual in data-acquisition systems).

Quantizing is measuring with a ruler that has only centimetre marks and no millimetres. A 1 m plank is measured well; a 3 mm washer reads as 0 cm. You can buy a ruler with finer marks (more bits) or make the object bigger before measuring (amplify).

Converter errors

Quantization error, saturation and the signal-to-noise ratio

Quantization error \(e_Q\): the difference between the analog input and the value represented by the output code. Its span is always one LSB: \(0\) to \(Q\) for a truncating converter, \(\pm Q/2\) with a ½-LSB bias. In an uncertainty analysis the resolution uncertainty is \(u_Q=e_Q\), usually \(\tfrac12 Q\).

As a varying signal climbs the staircase, \(e_Q\) traces a sawtooth between its limits that is unrelated to the signal itself. It therefore behaves like noise added to the record. Its absolute size is fixed, so it matters most for small signals.

Saturation error: an input outside \(E_{FSR}\) leaves the output stuck at the end code (all 0s or all 1s); the error is the difference between the input and that end value. Prevent it by conditioning the signal so it stays inside the range.

Conversion errors from the converter's own imperfections come on slide 12.

Resolution is often quoted as a signal-to-noise ratio (SNR). Where it comes from:

  1. The largest signal spans \(E_{FSR}\); the smallest change the converter can resolve is \(Q=E_{FSR}/2^M\).
  2. Electrical power goes as \(E^2/R\), so the ratio of the two powers is \((E_{FSR}/Q)^2=(2^M)^2\).
  3. In decibels: \(\text{SNR}=10\log_{10}(2^M)^2=20\log_{10}2^M\).
  4. Since \(20\log_{10}2=6.02\), every extra bit adds 6.02 dB.
Signal-to-noise ratio of an M-bit converter $$\text{SNR}=20\log_{10}2^M\approx6.02\,M\ \text{dB}$$

Worked example

Can a ±10 V data card see a one-degree change?

A temperature transducer produces 0.1 mV/°C. It is wired directly to a data card whose A/D converter has an input range of −10 to +10 V and a ½-LSB bias. Find the resolution \(Q\), the quantization error and the smallest temperature step the card can see for (a) a 12-bit and (b) a 16-bit converter. (c) What amplifier gain lets the 16-bit card resolve 0.05 °C, and does a 0–500 °C range still fit?

Known \(K=0.1\) mV/°C; range ±10 V; \(M=12\) or 16. Find \(Q\), \(e_Q\), step in °C, gain \(G\). Assumptions ideal converter, so only quantization matters.

  1. The span is \(E_{FSR}=+10-(-10)=20\) V, not 10 V.
  2. (a) 12-bit: \(Q=20/4096=4.88\) mV, \(e_Q=\pm2.44\) mV. In temperature: \(4.88/0.1=48.8\) °C per step, ±24.4 °C. Useless for this sensor.
  3. (b) 16-bit: \(Q=20/65\,536=0.305\) mV, \(e_Q=\pm0.153\) mV, i.e. 3.05 °C per step, ±1.53 °C.
  4. (c) An amplifier of gain \(G\) before the converter divides the input-referred step by \(G\). A 0.05 °C step is \(0.05\times0.1=5\ \mu\text{V}\), so \(G\ge0.305\ \text{mV}/5\ \mu\text{V}=61\). Take \(G=100\): step \(=3.05\ \mu\)V \(=0.031\) °C.
  5. Range check: 500 °C gives 50 mV, times 100 is 5 V, inside ±10 V with margin. (\(G=200\) would put 500 °C exactly at the 10 V limit.)

What this means: extra bits alone rarely rescue a millivolt signal. Gain before the converter, sized so the largest expected signal nearly fills the range, does.

Worked example · conversion errors

When the converter itself is imperfect

A 0–10 V, 12-bit A/D converter has a linearity error of 3 bits and a temperature drift error of 1 bit per 5 °C. It will work where its temperature may change by 10 °C. Estimate the design-stage uncertainty in its digital value of an analog voltage.

Known \(E_{FSR}=10\) V, \(M=12\), linearity 3 LSB, drift 1 LSB/5 °C, \(\Delta T=10\) °C. Find \(u_d\). Assumptions ½-LSB scheme; the error sources are independent, so they combine by root-sum-squares.

  1. One LSB: \(Q=10/4096=2.44\) mV.
  2. Quantization: \(u_0=\tfrac12Q=1.22\) mV.
  3. Linearity: \(u_2=3\ \text{LSB}\times2.44\ \text{mV}=7.32\) mV.
  4. Temperature: \(u_3=(10/5)\ \text{LSB}\times2.44\ \text{mV}=4.88\) mV.
  5. Conversion errors combined: \(u_c=\sqrt{7.32^2+4.88^2}=8.80\) mV.
  6. Total: \(u_d=\sqrt{u_0^2+u_c^2}=\sqrt{1.22^2+8.80^2}=8.89\) mV (95 % assumed).

What this means: the converter's own errors, not its resolution, dominate. A 12-bit converter with these specifications performs like one of roughly 9 bits.

Conversion error: error from imperfections inside the converter, delineated like any instrument error into linearity, zero, sensitivity, hysteresis and repeatability errors. Causes include settling time, noise during sampling, temperature effects and supply fluctuations.

Linearity error arises because the \(2^M\) steps are not exactly equal in width, so the staircase wanders from the ideal straight line. Converter errors are quoted in bits (LSB); multiply by \(Q\) to get volts.

Independent uncertainties add like perpendicular vectors: \(u=\sqrt{u_1^2+u_2^2+\dots}\). The largest one dominates; halving a small one changes the total very little.

A ruler with millimetre marks that were printed unevenly, on plastic that stretches in the sun. Finer marks do not help if the marks themselves are in the wrong place.

A/D converter types · successive approximation

Successive approximation: a binary guessing game played by hardware

  1. Set the MSB to 1, all other bits 0. The D/A gives \(E^*\). If \(E^*>E_i\) the comparator goes LOW and the bit is reset to 0; otherwise it stays 1.
  2. Set the next bit to 1 and repeat the test.
  3. Continue to the LSB. The final register is the converted value. One clock tick per bit, so \(M\) ticks per conversion.
Step (0–15 V, 4-bit, Ei = 10.1 V)RegisterE* (V)Result
MSB set to 110007.5HIGH: keep
next bit set to 1110011.25LOW: reset
next bit set to 110109.375HIGH: keep
LSB set to 1101110.3125LOW: reset
final10109.375\(e_Q=0.725\) V

Here \(Q=15/16=0.9375\) V and \(E^*\) for any word is \(X\cdot Q\). The output 9.375 V differs from 10.1 V by the quantization error; more bits would shrink it.

"I am thinking of a number from 0 to 15." Ask "is it 8 or more?", then "12 or more?", and so on. Four yes/no questions always pin it down. A 4-bit successive-approximation converter asks exactly those four questions.

Speed. \(M\) ticks per conversion: a 12-bit converter with a 1 MHz clock needs 12 µs. Typical boards reach 100 kHz to 1 MHz with 12 to 24 bits.

The input must not move during those \(M\) ticks, or later bits are decided against a different voltage than earlier ones. A sample-and-hold circuit in front captures the input at the sample instant and holds it constant while the register works.

A/D converter types · integrating

Ramp and dual-slope converters: slow, cheap and very quiet

A ramp converter charges a capacitor \(C\) from a constant current \(I\). Since \(q=\int I\,dt\), the capacitor voltage \(q/C\) rises linearly with time. A counter counts clock pulses while a comparator watches; when the ramp reaches \(E_i\) the count stops. The count is the digital value. A full-scale input needs \(2^M\) counts:

Maximum ramp conversion time $$t_{max}=\frac{2^M}{\text{clock frequency}}\quad(\times2\text{ for dual slope})$$

Its accuracy depends on \(C\), \(I\) and the clock. The dual-slope version removes the dependence on \(C\):

  1. Step 1: integrate \(E_i\) for a fixed time \(t_1\). The integrator output grows at a rate \(\propto E_i\) and reaches \(E^*=E_i t_1/RC\).
  2. Step 2: switch the integrator to a reference \(-E_{ref}\). The output falls at the fixed rate \(E_{ref}/RC\) and reaches zero after \(t_m=E^*RC/E_{ref}\).
  3. Substitute: \(t_m=E_i t_1/E_{ref}\). The product \(RC\) cancels.
Dual-slope conversion $$\frac{E_i}{E_{ref}}=\frac{t_m}{t_1}$$

Because step 1 integrates, noise averages out. If \(t_1\) is a whole number of mains periods (20 ms at 50 Hz), mains hum integrates to exactly zero. This makes dual-slope converters the choice for low-level (below 1 mV) signals and for digital voltmeters.

Dual-slope integratorintegrator outputwithout hum

With \(t_1=20\) ms, raise the hum to 3 V: the rising ramp wiggles, yet the reading stays exact. Switch to 15 ms and move the phase: the reading now errs by up to about 0.9 V. Choose 40 ms: exact again. Whole mains cycles integrate to zero.

Worked example · and the fastest converter

A ramp voltmeter, and the flash converter that decides in one tick

A 0–10 V digital voltmeter with a three-digit display (x.xx V) uses a 10-bit single-ramp converter and a 100 kHz clock. The input is 6.372 V. What does it display, and how long does the conversion take?

Known \(E_{FSR}=10\) V, \(M=10\), clock 100 kHz, \(E_i=6.372\) V. Find display, conversion time. Assumptions the ramp rises one LSB per clock tick; the count stops on the step where the ramp first reaches \(E_i\).

  1. \(Q=10/1024=9.766\) mV, so the ramp climbs 9.766 mV per step.
  2. Steps needed: \(6.372/0.009766=652.5\); the ramp first reaches \(E_i\) on step 653.
  3. Indicated value: \(653\times9.766\ \text{mV}=6.377\) V, displayed as 6.38 V. The difference from 6.372 V is quantization error.
  4. Each step takes \(1/100\ \text{kHz}=10\ \mu\)s, so the conversion takes \(653\times10\ \mu\text{s}=6.53\) ms. A dual-slope version needs about twice as long.

What this means: a few milliseconds per reading is nothing for a voltmeter but far too slow for vibration data.
