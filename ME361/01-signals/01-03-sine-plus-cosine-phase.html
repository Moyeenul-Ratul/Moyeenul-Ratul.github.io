Signal amplitude and frequency · phase

Sine plus cosine is one sine, shifted by a phase angle

Rotating arrow (phasor), ω = 4 rad/sy(t)B sin ωtA cos ωt

Set A = 0: the orange wave is a pure sine, φ* = 0. Set B = 0: a pure cosine, which is a sine shifted ahead by a quarter cycle (φ* = π/2 = 1.571 rad). Any mix gives a sine of length \(C = \sqrt{A^2+B^2}\).

The spring-mass solution \(A\cos\omega t + B\sin\omega t\) is really one sine. Expand \(C\sin(\omega t + \phi^*) = C\cos\phi^*\,\sin\omega t + C\sin\phi^*\,\cos\omega t\) and match terms: \(B = C\cos\phi^*\) and \(A = C\sin\phi^*\). Squaring and adding, or dividing, gives:

Amplitude and phase of a sine–cosine pair $$A\cos\omega t + B\sin\omega t = C\sin(\omega t + \phi^*)$$ $$\phantom{A\cos\omega t + B\sin\omega t} = C\cos(\omega t - \phi)$$ $$C = \sqrt{A^2+B^2},\qquad \tan\phi^* = \frac AB$$ $$\tan\phi = \frac BA,\qquad \phi = \frac\pi2 - \phi^*$$

The phase angle \(\phi^*\) says how far (in radians) the wave is shifted along the time axis relative to a plain \(\sin\omega t\). A positive \(\phi^*\) means the wave reaches its peak earlier by \(\phi^*/\omega\) seconds.

A Ferris wheel seen from the side: each seat goes up and down as a sine. Two seats on the same wheel have the same amplitude and frequency but reach the top at different times; that offset is the phase.

Here \(A = 3\), \(B = 5\), \(\omega = 4\) rad/s. \(C = \sqrt{9 + 25} = \sqrt{34} = 5.83\). \(\phi^* = \tan^{-1}(3/5) = 0.540\) rad, so \(y = 5.83\sin(4t + 0.540)\). As a cosine: \(\phi = \tan^{-1}(5/3) = 1.030\) rad, \(y = 5.83\cos(4t - 1.030)\). Period \(T = 2\pi/4 = 1.571\) s, \(f = 0.637\) Hz. These are the simulator’s default settings.
